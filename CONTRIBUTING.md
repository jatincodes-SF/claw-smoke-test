# Contributing Guidelines

Thank you for contributing to this project!

## Submitting a Change

To submit a change, please follow these steps:

1. **Branch**: Create a new branch from `main` with a descriptive name for your feature or fix (e.g., `feature/my-change` or `fix/issue-description`).
2. **Commit**: Make your changes and commit them with a clear, imperative commit message explaining the change.
3. **Open a PR**: Push your branch to GitHub and open a pull request against `main`. Provide a summary of the changes and any testing performed.
