# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

### Contact
Please send an email to security@example.com with details about the vulnerability.

### Process
1. **Details**: Include a description of the issue, steps to reproduce, and any relevant logs or proof of concept.
2. **Response**: We will acknowledge receipt of your report within 48 hours.
3. **Resolution**: We will investigate and work on a fix. Please do not disclose the vulnerability publicly until a patch has been released.
